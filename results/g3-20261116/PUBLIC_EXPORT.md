# 公开导出与校验

此目录保存十一城 18 条首稿、工具调用、失败和重试、独立评分，以及规则器 60 条对照记录。为公开仓库移除了本机绝对路径；`public-export-manifest.json` 分别记录每份本地原件和公开副本的 SHA-256。原始记录及冻结的评测源码继续保存在采集工作区；公开副本不宣称可重建原始文件的字节内容。

公开十一城快照移除与本版本范围无关的数据，并重建哈希清单，因此与原评测快照不是逐字节同一份。带登录上下文的 12306 原始响应未发布，公开的铁路观察仅为脱敏摘要；实际购票、余票和当前价格须重新核验。

发布前从 Git 索引重新检出，在该独立副本中验证了 profile 清单、南京南站别名和日期限定航班参考，并通过 34 项 G3 测试、13 项多段接驳测试、3 项公开导出测试，共 50 项。原始评测的冻结结果和后来单题复核结果分开记录在 [RESULTS.md](RESULTS.md)。
