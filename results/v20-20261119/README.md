# ChinaTravel V20 目录补全与交通预检

西安和厦门使用同一套十二城快照。沿用 V19 的 36 道 Easy／Medium／Human 题。每题按交通方式、到发顺序、规定天数和城际展示票价检查往返。 [V19 冻结评测](../v19-20261118/README.md)

| 通过项 | 西安 V19 → V20 | 厦门 V19 → V20 |
|---|---:|---:|
| 有符合时限的往返 | 16/18 → 18/18 | 14/18 → 18/18 |
| 城际展示票价在预算内 | 16/18 → 18/18 | 13/18 → 17/18 |

新增的航班和铁路样本使用 2026 年 11 月 20 至 22 日的页面观察。展示票价受日期、席别、税费和余位影响。预算预检只计城际票价。完整行程还涉及食宿、接驳和游玩时间。

北京出发的四道指定飞机题新增两城往返样本。武汉出发的厦门一日题已有预算内的同日往返。成都出发的厦门一日题最低展示价 ¥1,930，超过 ¥1,100 的总预算。成都两人两日指定铁路题最低票价 ¥4,104，剩余 ¥96，且最低价组合在厦门几乎只够过夜。

西安和厦门分别转换了 569 条和 420 条景点类别。厦门植物园、日光岩、菽庄花园补入交叉核验的 POI 关联，园博苑补入公共开放时段。西安补入部分有证据的菜系和西安城墙成人票。缺少证据的房价和菜系保持未知。

可运行 `python -B -X utf8 scripts/replay_benchmark12_v20.py` 离线核对目录计数、规划和评分的共享字段及 36 题交通对照。公开快照的收据校验公开文件，报告中的 `receipt_sha256` 对应本地输入，`public_receipt_sha256` 对应公开复现副本。来源链接和摘要位于快照中，原始响应保存在采集端。
