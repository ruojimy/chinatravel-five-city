## 复验

在仓库根目录运行 Python 3.10 或更新版本。脚本检查公开的两轮清单、V20 原始 CSV 哈希及源行、准入字段与最终目录。

```text
python -X utf8 results/shorttrip-2.2-data-20261124/verify.py
```

已有包含两个历史试排快照的 ShortTrip 2.2 安装时，可用安装自带的 Python 加 `--release` 重跑沙盒准入。该步骤检查全部 296 条记录的实际候选身份，以及入选记录的票价和开放时段字段，无需调用行程生成模型。

```text
python -X utf8 results/shorttrip-2.2-data-20261124/verify.py --release <ShortTrip安装目录>
```

此处的验收范围是双城免费景点的数据与试排资格。冻结快照、日期交通和基准场景的验收见 [V20 验证报告](../v20-20261119)。
