在仓库根目录运行以下命令可核对冻结题目、全部终态、行程评分摘要及目录计数。

```text
python -B -X utf8 results/shorttrip-data-acceptance-20261124/verify.py
python -B -X utf8 scripts/replay_benchmark12_v20.py
```

具备对应数据的 ShortTrip 2.2 安装时，用其 Python 3.12 执行下列脚本。`--output` 指向新路径。`replay_data.py` 加 `--database` 可对配置的 openGauss 做只读回查。规则重跑存在搜索时限和运行环境差异。

```text
python -B -X utf8 results/shorttrip-data-acceptance-20261124/replay_data.py --release <安装目录> --output <数据复验.json>
python -B -X utf8 results/shorttrip-data-acceptance-20261124/run_rule_planning.py --release <安装目录> --output <行程复验目录>
python -B -X utf8 results/shorttrip-data-acceptance-20261124/score_plans.py --release <安装目录> --plans <行程复验目录/run.json> --output <评分.json>
```
