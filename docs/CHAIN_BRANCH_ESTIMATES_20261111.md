# 连锁分店价格估计（2026-11-11）

## 规则

1. **严格品牌前缀**匹配，不用“青年旅舍/太空舱/酒店”这类通用词当品牌；
2. 只拿 **`source_value`** 的同品牌分店当 donor（避免用估价再估）；
3. 估计值 = donor 价格中位数；区间 = donor 最小–最大；
4. 单 donor 的链（易休太空舱、OYO、尚客优）标低置信，多 donor 的布丁（3 家）中等；
5. 状态 `estimated_chain_branch`；没有同链 donor 的青旅用 `estimated_hostel_comparable`。
