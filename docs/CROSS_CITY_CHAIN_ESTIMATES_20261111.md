# 跨城市连锁分店估计（2026-11-11）

## 方法

Xi'an 本城没有同品牌 donor 的连锁，改用扩展 catalog 的 **7,732 家 10 城酒店**做 donor：

```
norm_price = donor_price × median(Xi'an source_value) / median(donor_city)
estimate   = median(norm_price)
range      = min..max(norm_price)
```

- Xi'an 本城 source_value 中位数：**108 元**
- 城市中位数：上海 618、北京 637、深圳 518、苏州 498、杭州 464、广州 442、
  南京 405、成都 388、武汉 318、重庆 295
- 只接受可靠连锁 token：如家 / 汉庭 / 宜必思 / 星程 / 都市118 / 锦江之星
- 排除子场馆（大堂/前台/停车场/餐厅）与可疑同名（凯悦宾馆、万豪宾馆、雷派酒店）

## 剩余

- **9 家**有品牌但既无本城 donor、也无跨城 donor（或品牌太弱不采纳）；
- **343 家**无品牌/不可识别，继续 `-1`。

## 口径与风险

- 城市中位数归一化很粗：如家区间 30–122，说明不同城市分店差异很大；
- 单 donor 的锦江之星/都市118 只作低置信参考；
- 暂停营业的 2 家仍填了参考价，但规划时应继续被营业状态过滤；
- 全部是 `estimated`，报告不得写成 `source_value`。
