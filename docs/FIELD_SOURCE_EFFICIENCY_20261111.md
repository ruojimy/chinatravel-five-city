## 5. 结论

1. **高德是 name/坐标/营业时间/餐厅人均的主力**，餐厅人均 90.6% 命中，直接可用。
2. **景点票价只能靠官方/文旅**，地图 API 没有；这是景点 price 只有 3.2% 的结构性原因。
3. **酒店房价靠 Trip.com**（缓存回采最划算，实时页 38.8% 有详情），美团是次选，高德/百度为 0。
4. **连锁分店与缓存是零网络的高性价比补法**，但要严品牌、按城市中位数归一、标 `estimated`。
5. 剩余 352 家 unknown 里 343 家无品牌、9 家品牌太弱，继续走动态询价最稳。
